# 地层之下 · 现场垂直切片

这是第一版浏览器原型，目标是先跑通一条完整的游戏循环：

```text
中国地图情报 → 前往自贡石头冲 → 选择土格 → 铲土 / 毛刷 / 竹签 → 记录骨骼 → 归档图鉴
```

## 打开方式

直接双击 [index.html](index.html) 即可在浏览器中打开。页面不依赖构建工具，CSS、交互和示意素材都内置在单个 HTML 文件中。

## 当前垂直切片

- 地图页：显示四川自贡情报和其他待解锁区域。
- 现场页：川南红层丘陵、人工切坡、遮雨棚、发掘网格和分层地层。
- 操作：先用小铲清理表土；出现硬质物后切换毛刷；最后用竹签处理围岩。
- 线索：尾椎碎片、椎体、肋骨片段和零散骨片按逐步清理出现。
- 图鉴：完成记录后归档“和平永川龙（Yangchuanosaurus hepingensis）”科普卡片。

素材目前是手工粘土感的 CSS / SVG 示意，目的是确认界面语言、交互节奏和内容结构。下一轮可以把示意骨骼替换为按真实标本比例制作的 3D 模型，并把清理深度改为真正的体素或遮罩层。

## 事实边界

石头冲、1985 年村民修房发现尾椎、后续采集修理获得和平永川龙的叙事依据自贡恐龙博物馆公开资料。原型中的土格布局、地形比例和骨骼露出顺序是为了可玩性制作的演示布局，界面中已标注“依据真实事件改编”。
